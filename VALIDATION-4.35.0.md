# Проверка релиза 4.35.0 — «Понятные режимы обучения»

Дата: 31 октября 2026. Minecraft Java 1.20.1, Forge 47.4 / Java 17.
Основа — 4.34.0; Adapt Boost 1.7.0 и Distant Horizons 3.3.3 встроены побайтово прежними.
**4.35.0 заменяет 4.34.0**: тот же mod ID, те же версии протоколов (`WheelNetwork` "18", канал `learning` "1"),
ставится один файл вместо прежнего колеса.

По дизайну `learning-modes-2026-10-31`, ревизия 1 (утверждена в AdaptationHub 31 октября 2026).

## Что изменено

- `client/LearningScreen` переписан по макету: три карточки рядом (что делает режим, ✓/✗ «Готовые знания»,
  «Учится на ударах и эффектах», «Изучает моды и datapack заранее», нагрузка, «когда выбирать», кнопка
  «Выбрать (N)» / «Выбран» / «Недоступно»), выбранная обведена золотом, подсказка при наведении; строка наверху про
  одинаковую защиту; «Что уже знает анализатор» с полосой изучения мира (серая, когда изучение остановлено);
  «При смене режима». Оранжевая полоса, если режим задан сервером. Клавиши 1/2/3, ←→, Enter/Пробел.
- Узкое окно (ширина < 560 или высота < 340): список режимов слева («k/3»), карточка справа (наведённый или выбранный
  стрелками режим), ↑↓ и Enter, короткие строки статистики и полоса. Клик по строке выбирает режим.
- Новый чистый класс `client/LearningLayout` (раскладка, попадание мышью, «1 184», родительный падеж «до 1
  определения», состояние изучения). Тест `LearningLayoutTest` в `coreTest`.
- Новые названия режимов в обоих языках: «Только база», «Учится в бою», «Бой + изучение мира». Устаревшие ключи
  (`stats.facts`, `stats.experience`, `study.progress`, `guarantees`) убраны.
- `LearningConfig.definitionsPerSecond()`: нагрузку «до N определений в секунду» и пометку «По умолчанию» экран берёт из
  серверных настроек (Forge присылает их клиенту), а не пишет намертво. Сетевой протокол не менялся.
- Поле `modes` экрана (кнопки режимов) сохранено: проба `LearningQa` нажимает через него настоящие кнопки.
- `package-release.ps1` проверяет `LearningLayout.class` и новые ключи в обоих языках.

## Отступления от макета (сознательные)

- Строка наверху: в макете «Защиту, этапы и **скорость адаптации** … одинаково». Анализатор, которому режим даёт
  знания, уточняет категорию и время этапов, поэтому написано честнее: «Защиту, этапы и **ускорение от повторных
  ударов** колесо зарабатывает одинаково во всех трёх режимах».
- Список режимов в узком окне 160 px вместо 150: шрифт игры шире, чем в макете, и «3. Бой + изучение мира»
  обрезалось (видно на первом снимке, исправлено и пересобрано).
- В узком окне под карточкой невыбранного режима строка «Enter — выбрать этот режим» (в макете показан только
  выбранный).
- В сборке `untrained` первая строка — «Встроенные правила (без подготовленной базы)» вместо «Готовые знания (N)».

## Проверки

- `coreTest` во всех четырёх вариантах (`release-4.35.0.ps1`, чистая сборка с `check`): `LearningLayoutTest` на 17 633
  размерах GUI (320–1920 × 240–1080): панель в экране, карточки не налезают друг на друга и не уже 160 px, попадание
  мышью в карточки и строки, промежутки — не карточка, список, полоса сервера, статистика и полоса изучения не
  налезают на кнопки; 1146×472 — три карточки по 208 px, 462×265 — список и карточка; «1 184», «до 1/21
  определения», «до 8/11 определений»; стрелки останавливаются на краях. Остальные тесты — как раньше.
- GameTests **171/171** (`runGameTestServer` без встроенных jar) на итоговом коде.
- Настоящий клиент из копии `mc-runtime`, выпускной `dist/adaptation-wheel-1.20.1-4.35.0-trained.jar`
  (SHA-256 `eca05971…354a`), проба `LearningQa` (Ctrl+L из меню J, нажатие настоящих кнопок «Учится в бою», «Только

    **PASS**, 0 строк ERROR;
  - `learning-trained` (окно лаунчера 924×530, GUI 462×265), прогон `learning435r-compact-20261031-230618`:

## Честные границы

- Состояние «режим задан сервером» (`allowPlayerMode = false`) в настоящем клиенте не снималось: проба нажимает кнопки
  и с запретом не прошла бы; раскладка полосы проверена `LearningLayoutTest`, текст и неактивные кнопки — по коду.
- Подсказка при наведении в настоящем клиенте не снималась (проба не двигает мышь).
- OptiFine, пак Паши на 87 jar, шейдеры, выделенный сервер и GUI scale 3 на 3440×1417 (проверен тот же размер GUI
  1146×472) не запускались.
