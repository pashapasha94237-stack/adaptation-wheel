# Проверка релиза 4.33.3 — «Армиллярная сфера»: видно каждое кольцо

Дата: 30 октября 2026. Minecraft Java 1.20.1, Forge 47.4 / Java 17.
Основа — 4.33.2; Adapt Boost 1.7.0 и Distant Horizons 3.3.3 встроены побайтово прежними.
**4.33.3 заменяет 4.33.2**: тот же mod ID, та же версия протокола ("18"), ставится один файл вместо прежнего колеса.

По дизайну `armillary-all-rings-2026-10-30`, ревизия 1 (утверждена в AdaptationHub 30 октября 2026): модель m16.

## Что изменено

- `wheel_skins/armillary.json` — файл `m16.json` из AdaptationHub как есть. Коробки, крепление и свечение — m15
  (99 коробок, mount y −18,2; строки коробок отличаются только материалом); у второй половины сегментов каждого кольца
  другой материал: `horizonB` и `meridianB` бронза (было золото), `colureB` золото (было бронза), `eclipticB` новый
  материал `azure` (светлый лак). Скорости: обод со знаками +15°/с, большой вертикальный круг −24°/с, малый
  вертикальный +36°/с, эклиптика с тремя планетами −48°/с, звезда +72°/с, ось стоит. Код рендера не менялся.
- Подпись и описание облика (`skin.adaptationwheel.armillary.tagline/.description`, ru и en) говорят о двухцветных
  кольцах; `meta.adaptationwheel.changelog.4.33.3` в обоих языковых файлах.
- `SkinRigTest.armillaryRingsAllTurn`: облик — именно m16; прежние проверки m15 (одна неподвижная группа — ось, пять
  непересекающихся слоёв, соседние в разные стороны, внутренние быстрее) плюс новые: обод делает оборот не дольше чем за
  30 с; каждое из четырёх колец — две группы по 8 сегментов из одного несветящегося материала, с одной скоростью,
  сдвинутые на полсегмента (22,5°), и базовые цвета двух половин заметно различаются (сумма разниц RGB ≥ 90). На m15
  эта проверка падает: половины обода там обе золотые.
- `package-release.ps1` проверяет в каждом jar, что `armillary.json` — m16.

## Проверки

- `coreTest` во всех четырёх вариантах (`release-4.33.3.ps1`, чистая сборка с `check`): 6 обликов, **665 коробок**
  (как в 4.33.2); высоты `armillary` −28,4…−10,4 — те же; раскладка экрана облика на 17 633 размерах GUI.
- `armillary.json` внутри выпускного trained-jar побайтово равен `m16.json` из AdaptationHub; `package-release.ps1`
  проверил m16 во всех четырёх jar.
- GameTests **171/171** (`runGameTestServer` без встроенных jar).
- Настоящий клиент: группа `skins433-optifine` (OptiFine 1.20.1_HD_U_I6_pre6 + Configured 2.2.3, окно 2292×944,
  GUI 1146×472) на выпускном `dist/adaptation-wheel-1.20.1-4.33.3-trained.jar` (SHA-256 `dd186e0b…3b32`), клиент из
  копии `mc-runtime`, прогон `skins4333-release-optifine-20261030-153330`: **PASS, 50 проверок, 21 снимок**, ни одной
  строки ERROR с `adaptationwheel`. На снимках `skins-look-armillary` и `skins-world-armillary` сфера над головой, на
  ободе и кругах видны чередующиеся золотые и бронзовые сегменты, новое описание помещается в окне целиком (7 строк).
  Строка OptiFine «Ошибка OpenGL: 1282» в чате та же, что в прогоне 4.33.2 (по 10 упоминаний в обоих журналах).
- Выпуск: Adapt Boost 1.7.0 и DH 3.3.3 побайтово прежние (сверка до и после сборки и внутри каждого jar).
  SHA-256 — в `dist/adaptation-wheel-1.20.1-4.33.3-SHA256SUMS.txt`.
- Группы `skins433-wide` и `skins433-compact` не перезапускались: код экрана и рендера не менялся.

## Честные границы

- Само движение на снимках не видно: снимок — один кадр. Что каждое кольцо вращается со своей скоростью и его половины
  разного цвета, доказывает `SkinRigTest` по данным модели; рендер (`SkinRenderer.boxes`, `Group.angleDeg`) применяет
  `idleDegPerSec` и материалы без изменений с 4.33.0.
- Ограничение формата: все кольца вращаются вокруг общей вертикальной оси, вертикальные круги поворачиваются как глобус.
- Прежние границы 4.33.0 остаются: два живых клиента, шейдеры, выделенный сервер не проверялись.
- Модель `current.json` в AdaptationHub по решению Паши остаётся Золотым колесом: m16 — облик по выбору, колесо по
  умолчанию не изменилось.
